# เกี่ยวกับ veles

veles คือคู่มือรวมความรู้ของโปรเจกต์ ทั้งเครื่องมือที่ใช้ วิธีส่งงาน กติกาการเขียนโค้ด และระบบตรวจงานอัตโนมัติ เขียนให้ทั้งคนที่เขียนโค้ดและไม่ได้เขียนโค้ดอ่านเข้าใจ

<Simple>
  ลองนึกถึงคู่มือพนักงานใหม่ของร้านอาหาร: บอกว่าอุปกรณ์แต่ละชิ้นใช้ทำอะไร ออเดอร์เดินทางจากหน้าร้านไปครัวอย่างไร และอะไรที่ห้ามทำเด็ดขาด veles ทำหน้าที่แบบเดียวกัน แต่สำหรับโปรเจกต์ซอฟต์แวร์
</Simple>

<Detail>
  เนื้อหาเรียบเรียงจาก `docs/markdown/` ของ repo ต้นทาง (rule, planning, architecture) ถ้าเอกสารใน veles ขัดกับโค้ดจริง ให้เชื่อโค้ด แล้วแก้ veles ตาม
</Detail>

## อ่านอย่างไร

- **แบบง่าย / แบบละเอียด** ที่แถบด้านบน สลับระดับคำอธิบายได้ทุกหน้า
- คำที่มีเส้นประใต้ เช่น <Term id="branch" /> หรือ <Term id="migration" /> ชี้เมาส์เพื่อดูความหมาย
- กด <kbd className="kbd">Ctrl K</kbd> เพื่อค้นหาหัวข้อหรือคำศัพท์จากหน้าไหนก็ได้
- กด "อ่านจบแล้ว" ท้ายหน้า เพื่อนับความคืบหน้าในหน้า [เริ่มที่นี่](/) (จำไว้ในเบราว์เซอร์นี้เท่านั้น)

## แก้เนื้อหา

เนื้อหาแต่ละหน้าเป็นไฟล์ `.mdx` ใน `src/content/pages/` เขียนเหมือน Markdown ทั่วไป และใช้กล่องพิเศษเหล่านี้ได้เลยโดยไม่ต้อง import

| เขียนแบบนี้ | ได้อะไร |
| --- | --- |
| `<Simple>...</Simple>` | แสดงเฉพาะโหมดแบบง่าย |
| `<Detail>...</Detail>` | แสดงเฉพาะโหมดแบบละเอียด |
| `<Example>...</Example>` | กล่องตัวอย่างเฉพาะโปรเจกต์ |
| `<Warning>...</Warning>` | กฎที่ห้ามพลาด |
| `<Term id="commit" />` | คำศัพท์พร้อม tooltip |

<Example>
  กล่องนี้คือ `<Example>` ใช้ใส่สิ่งที่เป็นของโปรเจกต์นี้โดยเฉพาะ เช่น ชื่อ branch จริง หรือคำสั่งจริง ส่วนเนื้อหารอบๆ เขียนให้ใช้ได้กับทุกโปรเจกต์
</Example>

<Warning title="เพิ่มคำศัพท์ก่อนใช้">
  ถ้าใช้ `<Term id="...">` กับคำที่ยังไม่มีใน `src/content/glossary.ts` จะแสดงเป็นข้อความธรรมดา ให้เพิ่มคำในไฟล์นั้นก่อน
</Warning>

## นำไปใช้กับโปรเจกต์อื่น

1. แก้ `src/project.config.ts`: ชื่อโปรเจกต์ repo ชื่อ branch คำสั่ง และพอร์ต
2. แก้ `src/content/sections.ts` ถ้าอยากเพิ่ม ลบ หรือเรียงหัวข้อใหม่
3. เขียนเนื้อหาใน `src/content/pages/` โดยเก็บส่วนเฉพาะโปรเจกต์ไว้ใน `<Example>`

Theme ใช้ design system **Nocturnal Atelier v3.2** ชุดเดียวกับต้นแบบของ CMAS (`docs/pages/index-q-design-system.html`) โทเคนอยู่ใน `src/styles/tokens.css` ส่วนโหมดมืดอยู่ใน `dark.css` ซึ่งต้นแบบกำหนดสีมืดไว้แค่หกค่า ที่เหลือ veles คำนวณเพิ่มเอง
